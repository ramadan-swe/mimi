# Mimi Chat - تطبيق الدردشة 💬

تطبيق دردشة بسيط وسهل الاستخدام يعمل مباشرة في المتصفح بدون الحاجة لخادم!

## المميزات ✨

- 🚀 **سهل الاستخدام**: لا يحتاج إلى تثبيت أو إعداد معقد
- 💾 **حفظ تلقائي**: الرسائل محفوظة في المتصفح
- 🎨 **تصميم جميل**: واجهة عصرية وسهلة الاستخدام
- 🔄 **تحديث تلقائي**: تظهر الرسائل الجديدة تلقائياً
- 🌐 **يعمل بدون إنترنت**: بعد فتح الملف لأول مرة

## طريقة الاستخدام 📖

### الطريقة السهلة:

1. افتح ملف `chat.html` في أي متصفح (Chrome, Firefox, Safari, Edge)
2. أدخل اسمك
3. ابدأ الدردشة!

### للاستخدام المشترك على نفس الجهاز:

يمكن لعدة أشخاص استخدام التطبيق على نفس الجهاز/المتصفح:
- افتح الملف
- أدخل اسمك
- اكتب رسالة
- الشخص التالي يفتح نفس الملف ويدخل باسمه
- سيرى جميع الرسائل السابقة

### للاستخدام على أجهزة متعددة:

لمشاركة الدردشة بين أجهزة مختلفة، يمكنك:

1. **استخدام GitHub Pages** (مجاني):
   - ارفع المشروع على GitHub
   - فعّل GitHub Pages من إعدادات المستودع
   - شارك الرابط مع أصدقائك

2. **استخدام Netlify** (مجاني):
   - اذهب إلى [netlify.com](https://www.netlify.com)
   - اسحب ملف `chat.html` إلى الموقع
   - احصل على رابط مباشر للمشاركة

3. **استخدام خادم بسيط** (للمطورين):
   ```bash
   # باستخدام Python
   python -m http.server 8000
   
   # أو باستخدام Node.js
   npx serve
   ```

## مسح المحادثة 🗑️

- اضغط على زر "مسح المحادثة" في أسفل الشاشة
- أو امسح بيانات المتصفح (localStorage) للموقع

## التقنيات المستخدمة 🛠️

- HTML5
- CSS3 (مع تدرجات وأنيميشن)
- JavaScript (Vanilla JS - بدون مكتبات خارجية)
- localStorage للحفظ

# Mimi Chat - Simple Chat App 💬

A simple and easy-to-use chat application that works directly in the browser without needing a server!

## Features ✨

- 🚀 **Easy to use**: No installation or complex setup required
- 💾 **Auto-save**: Messages are saved in the browser
- 🎨 **Beautiful design**: Modern and user-friendly interface
- 🔄 **Auto-refresh**: New messages appear automatically
- 🌐 **Works offline**: After opening the file for the first time

## How to Use 📖

### Simple Method:

1. Open the `chat.html` file in any browser (Chrome, Firefox, Safari, Edge)
2. Enter your name
3. Start chatting!

### For Shared Use on Same Device:

Multiple people can use the app on the same device/browser:
- Open the file
- Enter your name
- Write a message
- The next person opens the same file and enters their name
- Everyone will see all previous messages

### For Use on Multiple Devices:

To share the chat between different devices, you can:

1. **Use GitHub Pages** (free):
   - Upload the project to GitHub
   - Enable GitHub Pages from repository settings
   - Share the link with friends

2. **Use Netlify** (free):
   - Go to [netlify.com](https://www.netlify.com)
   - Drag the `chat.html` file to the site
   - Get a direct link to share

3. **Use a simple server** (for developers):
   ```bash
   # Using Python
   python -m http.server 8000
   
   # Or using Node.js
   npx serve
   ```

## Clear Chat 🗑️

- Click the "Clear Chat" button at the bottom of the screen
- Or clear browser data (localStorage) for the site

## Technologies Used 🛠️

- HTML5
- CSS3 (with gradients and animations)
- JavaScript (Vanilla JS - no external libraries)
- localStorage for persistence
